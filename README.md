# Nassau Candy Optimization

## Project Overview
This project analyzes the Nassau Candy dataset to identify product trends and shipping optimization opportunities.

## Objectives
- Explore and clean the dataset.
- Analyze order and shipping dates.
- Calculate shipping lead times.
- Compare product performance.
- Visualize results.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Files
- `analysis.ipynb` - Data analysis notebook.

## How to Run
1. Open the notebook in VS Code or Jupyter Notebook.
2. Install the required Python libraries.
3. Run the notebook cells in order.
